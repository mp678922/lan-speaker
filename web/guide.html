Play your computer's audio on another device

The computer server is running. Follow these three steps to listen on a phone, tablet, or another computer.

First-time setup checklist

  • The Windows computer hosts the server. It needs Python 3.10 or later, a working default audio output, and a writable program folder. Internet access is needed to install packages on the first run.
  • Double-click start.bat in File Explorer and keep its window open. The receiving device needs a browser with Web Audio and WebSocket support, and a local network connection to the computer.
  • If the receiving device times out, a computer administrator may need to allow incoming LAN connections to the current TCP port. The troubleshooting buttons below can help you ask ChatGPT for guidance.
  • This website has no sign-in or encryption. Use a trusted local network and do not forward its port to the internet. See FIRST_USE.md in the program folder for the full checklist.
