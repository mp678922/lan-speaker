# 區網喇叭

[下載最新正式版](https://github.com/mp678922/lan-speaker/releases/latest) · [English](README.md)

將 Windows 電腦正在播放的聲音，透過區網傳到手機、平板或另一台電腦的瀏覽器。接收端不用安裝專用 App；電腦原本的聲音會保留，也不會擷取麥克風。

從[最新正式版](https://github.com/mp678922/lan-speaker/releases/latest)下載 **lan-speaker-v1.0.2.zip**，完整解壓縮後再執行 `start.bat`。也可用 **Code → Download ZIP** 取得目前 main 分支；此來源 ZIP 會依 `.gitattributes` 排除開發測試與 Git 設定檔，`git clone` 仍會包含測試。虛擬環境、快取與暫存檔則由 `.gitignore` 排除上傳。

## 首次使用準備

| 項目 | 需要準備 |
| --- | --- |
| Windows 電腦 | 可正常播放聲音的預設輸出裝置，以及可寫入的程式資料夾。 |
| Python | 3.10 以上。在 PowerShell 執行 `python --version`，應顯示版本號。 |
| 首次安裝網路 | BAT 會建立 `.venv`，依 `requirements.txt` 安裝 `aiohttp`、`numpy`、`SoundCard`；首次安裝或補裝缺少的套件時需要連網。 |
| 接收裝置 | 支援 Web Audio 與 WebSocket 的瀏覽器，能手動點播放並調整音量。 |
| 區網 | 兩台裝置必須能互連；電腦接有線、接收端用 Wi-Fi 也可以。訪客網路、VPN 或路由器的裝置隔離可能阻擋連線。 |
| 防火牆權限 | 如需新增輸入規則，請電腦管理員協助，只開放目前 TCP port 與同一區網來源（`LocalSubnet`）。 |

分享程式時保留 `start.bat`、`launcher.py`、`localization.py`、`server.py`、`config.json`、`requirements.txt`、完整 `web` 資料夾與 `assets/icons` 中的執行用圖示，並附上使用文件。不要把另一台電腦的 `.venv` 一起複製；新電腦首次啟動會自行建立。

## 啟動與播放

1. 在 Windows 檔案總管雙擊 `start.bat`，等待環境與套件準備完成，保持 BAT 視窗開啟。
2. 電腦瀏覽器會自動開啟引導頁，確認「電腦端狀態」顯示準備就緒。
3. 在接收裝置的瀏覽器輸入引導頁顯示的完整網址，包含 `http://`、電腦 IP 和 port。電腦重新連網後 IP 可能改變，請使用最新網址。
4. 在接收端點「開始播放」，調整裝置與網頁音量，並保持播放頁開啟。
5. 結束時關閉電腦 BAT 視窗，或在該視窗按 Ctrl+C。

播放頁的頻譜、光暈與粒子會跟著實際音訊變化；停止播放或頁面進入背景時會停止動畫。

## 語言與連接埠

播放頁與引導頁尚未手動選過語言時，會依瀏覽器第一偏好語系自動判斷：中文語系顯示繁體中文，其他或無法判斷時顯示英文。優先順序為「網址指定 → 已儲存的手動選擇 → 瀏覽器語系」。自動判斷不會寫入偏好，也不會強制分享網址的語言，接收裝置會自行判斷；手動選擇則會記住並帶入分享網址。ChatGPT 提問使用目前頁面語言，BAT 提示仍預設英文。

| 操作 | 指令 |
| --- | --- |
| 一般啟動 | 雙擊 `start.bat` |
| 指定中文提示與引導頁 | `start.bat --lang zh` |
| 指定英文提示與引導頁 | `start.bat --lang en` |
| 臨時指定 port | `start.bat 38471` |
| 同時指定 port 與中文 | `start.bat 38471 --lang zh` |

預設 TCP port 是 `38471`，可編輯 `config.json` 永久變更；指令指定的 port 只影響該次啟動。變更後需使用新網址，防火牆也要允許新 port。

`PASS` 表示同 port 已有本程式執行，這次只開引導頁。更新程式或要重新啟動時，先結束舊服務；重複開 BAT 不會取代它。

## 常見問題排除

### BAT 啟動不了

- 找不到 `python` 或跳出安裝商店：先安裝 Python，確認 `python --version` 可用。
- 套件安裝失敗：查看 BAT 錯誤，檢查網際網路與資料夾寫入權限。
- port 已被使用：換一個未使用的 port，再依上節更新網址與防火牆。

### 接收裝置逾時或打不開

每完成一步就重試一次：

1. 核對引導頁的最新網址與接收端輸入內容，尤其是 `http://`、IP 和 port。
2. 在電腦自己的瀏覽器開啟同一個區網播放網址。電腦也打不開時，查看 BAT 是否仍執行、網址是否正確；只有接收端逾時時，再查區網互通與輸入防火牆規則。
3. 確認兩端不是被訪客網路、VPN 或路由器裝置隔離分開。需要接收端 IP 時，從該裝置的 Wi-Fi／網路詳細資訊查看，選單依系統而異。
4. 請管理員確認目前 TCP port 的輸入規則，來源限制為 `LocalSubnet`，不必關閉整個防火牆。
5. 若服務由 IDE、Agent 或隔離命令環境啟動，可能本機能開、其他裝置卻無法連線。結束該服務，再從檔案總管雙擊 BAT；仍顯示 `PASS` 代表舊服務還在。

仍無法解決時，記錄兩端系統、接收端瀏覽器與完整錯誤、實際網址、兩端 IP，以及電腦開同一網址的結果。請勿在公開討論區貼上非必要的內部 IP 或電腦名稱。

### 播放頁能開但沒有聲音

1. 在接收端手動點「開始播放」，確認裝置與網頁音量都不為零。
2. 讓電腦播放確定有聲音的內容，確認預設輸出裝置、靜音狀態，以及引導頁是否有擷取錯誤。
3. 查看接收端連線狀態。中斷時保持頁面在前景，重新整理後再點播放。
4. 更換電腦預設輸出裝置後，等待狀態更新；仍無聲時重新啟動 BAT，再依最新網址連線。

### 使用 ChatGPT 排查

引導頁「常見問題排除」預設收合，展開後可依「電腦能開、接收端逾時」「兩端都打不開」或「沒有聲音」開啟對應提問。

程式會在電腦本機唯讀收集播放網址、port、音訊狀態、程式路徑、網路設定檔及具名防火牆規則。這些資料只涵蓋部分狀態，不能直接證明網路或防火牆已正常。

**按下 ChatGPT 按鈕時，診斷資料會隨網址傳送。** 對話仍由使用者確認後送出；不想分享時可使用上述手動流程。GPT 只能依提問與後續回覆提供文字引導，無法查看或操作裝置，也不知道先前設定或專案檔案。

## 使用限制與隱私

- 僅在可信任的區網使用。網站沒有登入驗證或傳輸加密；同區網的人若知道網址，也可能播放。不要設定路由器對外 port 轉發。
- 電腦與接收端同時出聲可能產生回音。部分受保護音訊可能無法擷取。
- 切換 App、分頁或鎖定螢幕後，瀏覽器可能暫停音訊；背景播放需依裝置與瀏覽器實測，無法保證持續。
